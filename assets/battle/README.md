# Battle visual cues

Local SVG assets: a yellow geometric manual-skill readiness marker and a shaded panelled football. They are project drawings, not extracted Arknights textures. Research identified the source game's football device as trap_165_muftbl; the available device avatar is a restart symbol, not its battle model. No external runtime or artwork license is added by these drawings.

References: https://prts.wiki/w/足球 and https://prts.wiki/w/技能 . Assets only affect rendering; readiness comes from the carried skill and existing SkillRules.can_activate. Ball position, collision and force remain simulation-owned.
