# Bagpipe battle visual bundle

Default front/back battle skeletons: Spine 3.8.99, single 512x512 straight-alpha atlas page per view. Source URLs, pinned revision and file hashes are in source_manifest.json. runtime_manifest.json identifies the user-supplied unmodified SpineBridge plugin. Runtime notices remain in addons/spine_bridge and exported licenses/spine_bridge.

Generate bagpipe.res with tools/import_bagpipe_visual.gd using Godot 4.7.2 and the supplied native extension. Gameplay resources remain under resources/operators; these assets only supply visual poses. Animation events never determine combat.

Local experimental use is approved by the user. No project-owned license is granted for the Arknights artwork; public distribution requires separate scope confirmation.
